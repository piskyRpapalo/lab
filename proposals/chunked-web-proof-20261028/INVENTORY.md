## Local implementation state

`generate_model.py` creates a synthetic, sparse fixed-point 4-class table. Its 25,000,000 B payload is four consecutive 6,250,000 B files; SHA-256 is checked per file. Only the demo's fixed vocabulary has nonzero weights, and unknown/tied categories return cause-bearing `NO_DATA`. This proves deterministic transport and a bounded local classifier, not trained-model usefulness.
