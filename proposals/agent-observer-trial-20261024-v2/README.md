## Watch-mode design (documentation only)

A future Mesa scheduler may run the command at a fixed interval, retain each JSON receipt as an immutable artifact, and pass the immediately previous receipt on the next run. It should diff only adjacent receipts, alert on head/status/listener changes, preserve `NO_DATA` distinctly, and keep artifacts access-controlled. It must not attach to processes, connect to ports, enter Claude's worktrees to build, or mutate the observed session log. No scheduler or daemon is included here.
