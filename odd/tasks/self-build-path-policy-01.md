# SELF-BUILD path policy correction

Independent review of LAB #192 found sensitive paths accepted under a permissive
host allowlist and synthetic positive witnesses. This was not an authorization
or execution. The ordinary proposal route now refuses protected path classes:
Git metadata, nested agent instructions, governance and permission directories,
CI/tests, installation/deployment entrypoints, and the entire meta-harness core.
The last class is deliberately conservative: its feature-only modules need a
separate sovereign review too. Ordinary allowlisted docs and feature files remain
eligible for proposal; no path rule is a signature or replaces a Git witness.
Callbacks remain synthetic in tests. This is a path-name policy, not proof of
rename, symlink, executable behavior, or complete coverage of every ecosystem
policy file. Next: read-only host-configured Git witness; distinguish source
provenance, review and authorization. Rollback: revert this commit with review.
